01

Открытый исходный код

Каждая строка доступна для проверки. Хочешь — подними свой сервер или собери свой клиент. Возможности бесконечны.

02

Сквозное шифрование

Каждое сообщение шифруется AES-256-GCM на твоём устройстве. Сервер видит только шифр, не содержимое.

03

Мгновенная доставка

Сообщения уходят прямо к собеседнику через WebSocket. Никаких задержек и посредников.

04

Свои сервера

Разверни сервер Flash на своём железе. Приглашай только своих — закрытый сервер. Или открой для всех.

05

Без рекламы и слежки

Ноль метаданных, ноль трекеров, ноль аналитики. Только ты и твои собеседники.

Безопасность

Твоя переписка —
только твоя.

Мы построили Flash с нуля вокруг приватности. Шифрование происходит на твоём устройстве — ключи не покидают клиент.

  • Шифрование end-to-end Каждое сообщение зашифровано ключом, который есть только у тебя
  • Свой сервер — свои правила Ты решаешь, где хранятся данные. Никто, кроме тебя, не имеет доступа
  • Без рекламы навсегда Никаких баннеров, трекеров и сбора данных
  • Открытый код Весь код клиента и сервера открыт — проверь сам
